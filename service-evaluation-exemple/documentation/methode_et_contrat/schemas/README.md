# Les schémas du contrat

Un schéma JSON par fichier échangé entre le service et un RAG (corpus, morceaux de texte, recherches, réponses…). Le service s'en sert pour vérifier chaque fichier et dire précisément ce qui manque (`kit verifier-contrat`). Leur description en clair : [`contrat_des_fichiers.md`](../contrat_des_fichiers.md).
