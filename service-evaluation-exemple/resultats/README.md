# Nos résultats

Ce que le service a produit sur le RAG d'exemple. Les résultats se lisent depuis [la page de l'exemple](../README.md).

| Élément | À quoi il sert |
| --- | --- |
| [`evaluations/`](evaluations/) | les 4 configurations évaluées, chacune avec son `RAPPORT.md` |
| [`comparaisons_de_configurations/`](comparaisons_de_configurations/) | les 2 comparaisons avec la référence, chacune avec son `RAPPORT.md` |
| [`corpus/`](corpus/) | la version du corpus utilisée, contrôlée par le service |
| [`reponses_du_rag/`](reponses_du_rag/) | ce que le RAG a rendu, pour chaque configuration |
