# Les réponses du RAG

Ce que le RAG a rendu par ses quatre endpoints, une version du RAG par dossier : sa description (`rag.json`), ses morceaux de texte (`chunks.jsonl`), les pages lues, ses recherches et ses réponses. Le service les vérifie avant d'évaluer.

Exemple rempli : [`service-evaluation-exemple/resultats/reponses_du_rag/`](../../../service-evaluation-exemple/resultats/reponses_du_rag/).
