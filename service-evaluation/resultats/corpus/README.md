# Les versions du corpus

Chaque import du fichier Excel (`kit importer`) contrôle le corpus et en range ici une version, `<date>.<numéro>/` : les documents, les questions, les passages et les pages retapées, dans des fichiers que n'importe quel RAG sait lire.

Exemple rempli : [`service-evaluation-exemple/resultats/corpus/`](../../../service-evaluation-exemple/resultats/corpus/).
