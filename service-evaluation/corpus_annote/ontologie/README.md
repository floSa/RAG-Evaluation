# L'ontologie du domaine (facultatif)

Seulement si votre RAG construit un graphe de connaissances. Mettre ici l'ontologie du domaine (les types d'objets et de liens) et ses règles, au format SHACL, dans `ontologie_formes.ttl` : le service vérifie que le graphe du RAG les respecte. Comment, et ce que ce contrôle ne dit pas : [Pour aller plus loin : les cas particuliers](../../documentation/cas_particuliers.md#1-un-rag-avec-un-graphe-de-connaissances).

Le RAG d'exemple n'a pas de graphe : ce dossier reste vide dans l'exemple.
