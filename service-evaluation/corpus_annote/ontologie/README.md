# L'ontologie du domaine (facultatif)

Seulement si votre RAG construit un graphe. Mettre ici l'ontologie du domaine (les types d'objets et de liens) et ses règles, au format SHACL, dans `ontologie_formes.ttl` : le service vérifie que le graphe du RAG les respecte ([guide 1](../../documentation/1_evaluation_ingestion.md)).

Une ontologie remplie, pour voir : [`service-evaluation-exemple/corpus_annote/ontologie/`](../../../service-evaluation-exemple/corpus_annote/ontologie/).
