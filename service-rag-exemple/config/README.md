# Les réglages du RAG

| Élément | À quoi il sert |
| --- | --- |
| [`config.yaml`](config.yaml) | les modèles (génération, embeddings), le nombre de morceaux ramenés (k), la taille des morceaux, le graphe activé ou non, l'adresse des endpoints |
| [`ontologie.ttl`](ontologie.ttl) | l'ontologie du domaine, qui guide la construction du graphe |
